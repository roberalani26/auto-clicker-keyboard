# Auto Clicker with Keyboard Control

An auto clicker for Windows that you control from the keyboard. Assign a key, press it once
to start, press it again to stop — without alt-tabbing out of your game or application.

## Download

[Download the latest release](../../releases/latest) — one file, no installer.

## Why the keyboard matters

Most clickers make you switch back to their window to stop them. This one listens for a
global hotkey, so the game keeps focus and nothing interrupts what you are doing.

## Settings

- Any key or combination as the start and stop hotkey
- Click interval in hours, minutes, seconds or milliseconds
- Fixed point on screen or wherever the cursor happens to be
- Left, right or middle button, single or double click
- Endless mode, or a set number of clicks

## Requirements

Windows 10 or 11, 64-bit. Portable, no admin rights needed.
